# Atlas Eléctrico de México

Dashboard interactivo para explorar el sistema eléctrico mexicano, desde los recursos energéticos hasta el consumidor. Proyecto TE1020 · FotoV.

## Publicar en GitHub Pages

1. Descarga y descomprime este paquete.
2. Crea un repositorio nuevo en GitHub y carga **el contenido** de esta carpeta (incluidos `assets/` y `.nojekyll`).
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio; la URL aparecerá en esa misma sección.

La aplicación es estática: no requiere instalar dependencias ni compilar.
